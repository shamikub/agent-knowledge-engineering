# AI Agent 知識工程

12 週正課與 6 堂實驗。全課共用一趟虛構的雙人歐洲自由行。行程中的跨日夜車、洗衣與烘衣差異、彈性班次與硬性入住期限，取材自真實旅遊問題。教材資料均為合成。

每週約 5–6 小時。先讀講義並手算，再讀原文的任務、基線、結果與限制，雙週完成一堂 Lab。每個 Lab 的 README 交代背景，SPEC 給作業，EXPECTED 給可重跑的驗收。先跑基線，再改一個變因，最後解釋一筆反例。

## 開始

**先讀前置章節**（建議所有學員在第 1 週前完成）：
[知識工程師的角色與協作](lectures/chapter0/intro.md)

**環境需求**：Python 3.10+。預設路線使用標準函式庫，資料與模型推論以外的測試可以離線執行。選修模型和套件首次使用需要下載。

```bash
python3 course.py 01
python3 -m unittest discover -s tests -v
```

依序把 `01` 換成 `02` 到 `06`。基線程式可閱讀及修改，練習以規格裡的反例和對照實驗為主。使用 Git commit 保存每次實驗，所有課程檔案放在同一個專案。

## 學習路徑建議

### 我是完全的初學者
1. 先讀 [Chapter 0：角色與協作](lectures/chapter0/intro.md) 建立全局觀
2. 按週次順序讀講義，每節讀完做課文裡的練習題
3. Lab 先讀 README，確認能回答「這個 Lab 要解什麼問題」再開始
4. 卡住時先看 SPEC 裡的提示，再看 EXPECTED

### 我有一些工程背景
1. 先看課程地圖，找出自己不熟的部分
2. 每章直接跳到「方法比較與選型」，確認自己的選型直覺
3. 用 Lab 的 EXPECTED 做反向工程：看答案，解釋為什麼

### 我想直接做專案
1. 讀 Chapter 0 了解全局
2. 先做 Lab 01-03（資料採集到知識表示）
3. 建立評估資料集（Chapter 5）再開始建系統

## 論文與前沿作業

每章記錄查核日期、論文或官方榜單 URL、資料集、切分、指標、模型設定、運算代價與一個限制。若公開結果的設定不同，寫出差異。講義連的是代表方法及評估來源，當期榜首請依作業查核。

## 期末交付

六個 Lab 的命令與實驗紀錄、一張基線比較表、一份錯案診斷、可重播的行程看板。每項建議顯示來源、未知欄位與是否需要人工確認。依正確性與證據 40%、實驗設計 30%、診斷 20%、可重現性 10% 評分。

**期末報告模板**：
```
系統概覽
 - 處理的問題類型
 - 採用的管線架構（附圖）
 - 每個模組的選型理由

評估結果
 - 整體指標
 - 各切片分析（至少 4 個切片）
 - 與基線的比較

錯案分析
 - 選 3 個最具代表性的錯案
 - 每個說明：問題、根本原因、改進方向

實驗記錄
 - 改了什麼變因、結果如何、結論是什麼

已知限制與後續計畫
```
