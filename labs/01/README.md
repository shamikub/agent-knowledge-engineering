# Lab 01 · 現場證據

## 情境說明

你和朋友計畫一趟雙人歐洲自由行，行程橫跨西班牙、奧地利、德國與法國。為了省錢，你們訂了一班從馬德里出發的夜間巴士，4 月 12 日深夜 23:50 開車、隔天清晨 06:40 抵達目的地。現在你需要用程式把這趟夜車的「跨日」時間資訊正確解析出來，同時整理四條訂位事件的完整軌跡，才能知道哪些訂位曾經取消又重訂、哪些一路順暢。

## 你會學到什麼

- 如何從非結構化文字中擷取日期與時間，並正確處理「跨日」的邊界情況
- 什麼是「流程事件軌跡」（event trace），以及如何建立直接相鄰圖（directly-follows graph）
- 如何透過圖的邊計數，發現訂位流程裡的異常路徑（例如取消後重訂）
- 為什麼同一筆流程刪掉一個事件後，圖的結構會產生質變

## 開始前確認

- 已讀完 [第 1 章講義](../../lectures/chapter1/intro.md)（文件、語音與流程探勘）
- 熟悉 Python 的 `datetime` 模組基本用法
- 了解什麼是有向圖（directed graph）的節點與邊

## 執行方式

從倉庫根目錄執行下列指令，觀察基線輸出：

```bash
python3 course.py 01
```

執行後你應該看到夜車抵達時間、以及四條訂位軌跡所產生的直接相鄰圖邊計數。接著根據 [SPEC](SPEC.md) 修改程式，再跑一次確認結果符合 [EXPECTED](EXPECTED.md)。

## 可能卡住的地方

- **夜車的抵達時間為什麼是 4 月 13 日而不是 4 月 12 日？** 想想看「23:50 出發、06:40 抵達」代表的是隔天，程式怎麼判斷這個跨日邏輯？
- **刪掉 T2 的取消事件之後，邊的計數為什麼會同時新增又消失？** 試著把 T2 原本的完整軌跡畫在紙上，再把取消那一步拿掉，看看連接關係如何改變。
- **「直接相鄰」的定義是什麼？** 相鄰是指序列中緊接在一起的兩個事件，還是任意兩個事件之間都算？這個差別對圖的形狀有什麼影響？

## 驗收標準

核對 [EXPECTED.md](EXPECTED.md)，重點確認：

1. 夜車抵達時間：解析結果必須是 `2026-04-13T06:40:00`，來源標示 `D1`
2. 取消→重訂的邊計數為 1（來自 T2）
3. 修改 T2 刪去取消事件後，「取消→重訂」邊消失，「預訂→重訂」邊新增

驗收指令：

```bash
python3 course.py 01
python3 -m unittest discover -s tests -v
```
