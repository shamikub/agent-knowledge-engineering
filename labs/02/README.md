# Lab 02 · 審核佇列

## 情境說明

旅途中，你和朋友在聊天記錄裡討論是否要改票。這些對話被兩個自動標註器（標註器 A 與標註器 B）各自打上標籤，判斷每句話的「訂位意圖」屬於哪個狀態（例如：提議、已訂、取消）。問題是，兩個標註器有時意見一致、有時分歧，而你只有有限的預算能請人工去審核幾筆。要怎麼決定先審哪幾筆，才能最有效地找到錯誤？

## 你會學到什麼

- 什麼是「弱監督學習」（weak supervision）以及多個標註器分歧時代表什麼
- 兩種審核抽樣策略的差異：**隨機抽樣** vs. **分歧優先抽樣**
- 在固定預算下，哪種策略平均而言能更快找到標註錯誤
- 當兩個模型一致但同時都錯時，分歧策略會有什麼盲點

## 開始前確認

- 已讀完 [第 2 章講義](../../lectures/chapter2/intro.md)（資訊萃取與專家校對）
- 理解什麼是「標註一致性」（inter-annotator agreement）
- 知道什麼是隨機種子（random seed）以及為什麼實驗需要固定種子

## 執行方式

從倉庫根目錄執行下列指令，觀察基線輸出：

```bash
python3 course.py 02
```

執行後你應該看到在不同抽樣策略下，各自找到的錯誤數量。接著根據 [SPEC](SPEC.md) 修改程式，跑多組 seed 取平均，再核對 [EXPECTED](EXPECTED.md)。

## 可能卡住的地方

- **分歧策略為什麼預算 2 就能先找到 M3 和 M4？** 看看 M3 和 M4 的標註器 A 與 B 的答案，想想「分歧」的定義是什麼，哪些資料列符合這個條件。
- **為什麼要跑 20 個不同的 seed？** 單跑一次隨機抽樣的結果可能很好也可能很差，seed 的用途是什麼？平均多次跑的結果又說明了什麼？
- **「兩模型一致但同時錯」是什麼意思？** 試著在資料裡找看看：有哪一筆，A 和 B 給了相同答案，但這個答案和正解不同？分歧策略會選到這筆嗎？

## 驗收標準

核對 [EXPECTED.md](EXPECTED.md)，重點確認：

1. 預算為 2 時，分歧策略會先選 M3 和 M4，並找出標註器 A 的兩筆錯誤
2. 多 seed 實驗報告出隨機策略的平均表現
3. 新增了一筆「兩模型一致但同時錯」的案例，並分析分歧策略是否能發現它

驗收指令：

```bash

```
