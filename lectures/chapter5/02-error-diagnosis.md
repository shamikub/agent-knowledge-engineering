# 5.2 四次重跑定位錯因

固定同一案例與答案模組，依序比較實際檢索、人工確認的證據、正確證據加干擾項、正確證據但拿掉必要欄位。檢索換成 oracle 後成功，表示正確證據有幫助，下一步比較候選召回、排名和過濾。若 oracle 仍失敗，再比對結構化欄位、時間運算與最終處置。固定執行設定，模型有隨機性時做多次重跑，避免把抽樣差異當成原因。

| 觀察 | 下一步 |
|---|---|
| 正確條款不在候選 | 查匯入、切段、索引與過濾 |
| 候選中有條款但排名太低 | 固定候選比 reranker |
| 加入舊版才答錯 | 固定位置測版本與來源提示 |
| oracle 下仍算錯取消期限 | 將時間比較獨立交給程式驗證 |

引用另拆成正確性與完整性。引用正確性問該證據是否支持對應的說法，引用完整性問有多少需引用的說法真的得到支持。兩段引用都正確，仍可能漏掉最關鍵的改票截止規則。用 ALCE 的評估思想設計標註。對較難判的時間與否定例外人工複核。
