# 4.5 從檢索到回答

「現在取消會不會被收費」至少涉及訂位時間、現行取消條款和當下時間。先用 metadata 選適用版本，再找兩段證據，最後把時間比較交給確定性的程式。標註 qrels 時同時記錄哪些文件單獨相關、哪些組合才足以回答。量三層：候選是否齊全、回答是否正確、引用是否支持結論。

**驗收反例。** Q3 在 k=2 時 nDCG 可以是 1，因為前兩名都相關，但回答需要三份文件。再用同一筆案例比較 k=3，並執行含舊條款與不含舊條款的對照。注意一筆錯答可能是主要證據遺失，也可能是檢索齊了但選用過期規則。

**研究討論。** 固定 BEIR 或 MIRACL 單一切分，比一個稀疏和一個 dense 方法。記錄語言、訓練集合、是否重排、指標和日期。再回到旅行資料做一次失敗分析，找出公開榜單沒有測到的時態或版本問題。
