# 2.2 弱標註怎麼學

Labeling function 對一筆輸入投類別或 abstain。組成的矩陣每列是案例、每欄是來源。多數決是一條基線。Snorkel Label Model 用來源的一致與衝突估可靠度，產生每筆資料的機率標籤。來源若共享同一訊號，獨立假設可能高估該訊號。

**算例。** 三條規則投已訂、已訂、候補。前兩條都只從同一封信抓「訂」字，第三條讀狀態欄。多數決得已訂。合併同源規則後是平票，此案值得送審。用獨立人工標註估各來源精確率，分信件模板報告。覆蓋率很高的規則仍可能在特定模板全錯。
